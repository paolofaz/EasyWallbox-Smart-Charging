# EasyWallbox Smart Charging 0.0.1 — pre-alpha

**Release di prova, esclusivamente per verificare l'installazione Marketplace e il Config Flow.**

## Cosa contiene
- Manifest dell'integrazione `easywallbox_smart` per Home Assistant 2026.11+.
- Configurazione grafica per selezionare i sensori esistenti della wallbox, delle auto e dei tre Shelly EM.
- Options Flow e traduzioni IT/EN.
- Documentazione, test statici e definizione preliminare della dashboard Lovelace.

## Cosa NON contiene
- Nessuna lettura in tempo reale o sensore calcolato.
- Nessuna identificazione auto, stima di energia, pianificazione o dashboard funzionante.
- Nessun servizio o comando verso wallbox/Fiat/Kia: il DPM e le automazioni esistenti sono lasciati invariati.

## Test e avvertenze
- Controlli statici in CI; installazione e Config Flow non ancora verificati su Home Assistant reale.
- Installare **solo selezionando questa pre-release**, non il branch di default `main` che contiene soltanto una licenza.
- Segnalare eventuali errori di installazione o config flow con estratto del log, **senza credenziali, PIN o dati personali**.

**Obiettivo:** milestone successiva v0.1 completamente in simulazione, con Lovelace dedicata.
